# Turning the Sound System On

This guide explains how to verify and turn on the Mackey Hall sound system. Do this before using microphones, computer audio, or Bluetooth audio.

If the system is already on, no changes are needed.

## At a Glance
- The rack power switch should be lit red.
- The amplifier power button should be lit blue.
- After both are on, use the iPad audio controls to choose what you want to hear.

## Check Rack Power
1. Go to the sound system rack.
2. Find the red `Power` switch on the rack.
3. If the switch is not lit red, turn it on. If it is already lit, leave it as-is.

![Rack Power Switch](../../assets/images/audio/sound_system_on-off/power-new.png)

## Check Amplifier Power
1. Locate the amplifier in the rack (third unit from the bottom).
2. Press the amplifier power button at the bottom-right.
3. Confirm the button lights blue, which means the amplifier is on.

![Amplifier Power Button](../../assets/images/audio/sound_system_on-off/power-new_amplifier.png)

## Sound System Ready
When the rack power is on and the amplifier power button is blue, the sound system is ready for microphones, computer audio, and Bluetooth audio.

## If You Still Do Not Hear Sound
- Make sure the iPad audio controls are on the right preset.
- Make sure the channel you need is not muted.
- Raise the channel level gradually, then raise the `Speakers` or `Master Output` level if needed.
- If using a computer or Bluetooth device, make sure the device volume is also turned up.

## Technical Note
The rack power supplies the sound equipment. The amplifier drives the room speakers. Both need to be on before the iPad controls can send audio through the room.
